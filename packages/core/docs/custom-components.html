自定义组件系统

Grid Table提供了一套强大的自定义组件系统，允许开发者定义和注册自己的单元格组件， 以实现更复杂的数据展示和编辑功能。

组件注册

通过组件管理器可以注册自定义视图和编辑组件，支持函数组件和类组件两种形式。

组件接口

interface IComponent {
  init(params: IComponentParams): void;
  getGui(): HTMLElement;
  refresh?(params: IComponentParams): boolean;
  destroy?(): void;
}
